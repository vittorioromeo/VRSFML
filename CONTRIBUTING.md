# Contribution Guidelines

Want to see a feature implemented or a bug fixed in Zancle? Great! Contributions are highly appreciated, be it in the form of general ideas, concrete suggestions, or code patches.

Before opening an Issue or Pull Request, please consider the project's scope and design priorities described in [DESIGN.md](DESIGN.md). Zancle is an opinionated fork of SFML focused on modern C++, web deployment, type-safe APIs, aggressive compile-time performance, and a more data-oriented design. Contributions that respect those priorities are most likely to land.

For project-history context and motivation, see Vittorio's three blog posts:
- <https://vittorioromeo.com/index/blog/vrsfml.html>
- <https://vittorioromeo.com/index/blog/vrsfml2.html>
- <https://vittorioromeo.com/index/blog/vrsfml3.html>
